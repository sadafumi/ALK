# Albedo Shading Baker (Unity Editor 拡張)

メッシュから**法線マップをベイク**し、そこから**陰影マスク（Lambert / 中間 0.5）**を生成する Unity エディタ拡張です。
法線マップを持たないモデルでも、メッシュ形状から陰影テクスチャを作れます。

パイプライン: **メッシュ → 法線マップ（UVへベイク）→ 陰影テクスチャ**

## 導入

1. `AlbedoShadingBaker` フォルダを、プロジェクトの `Assets` 以下にコピーします。
   - `Assets/AlbedoShadingBaker/Editor/*.cs`
   - `Assets/AlbedoShadingBaker/Shaders/*.shader`
2. Unity がコンパイルすると、メニューに **Tools > Albedo Shading Baker** が追加されます。

> 動作確認: Unity 2020.3 LTS 以降（Built-in / URP / HDRP いずれのパイプラインでも、ベイク自体はカスタムシェーダで完結するため利用可能）。

## 使い方

1. **Tools > Albedo Shading Baker** を開きます。
2. `共有アルベド` にテクスチャを割り当てます（保存名・自動収集の基準にもなります）。
3. `メッシュ` に、MeshFilter / SkinnedMeshRenderer を持つ GameObject か、Mesh を **複数**登録します。
   - `＋ 空きスロットを追加` / `選択中を追加` / `クリア` で編集できます。
   - `このアルベドを参照するシーン内メッシュを収集` を押すと、同じアルベドを使っている
     シーン内メッシュをまとめて追加します。
   - メッシュには **UV（uv0）展開が必須**です（UVの無いメッシュは自動でスキップ）。
4. 解像度・法線空間・縁の埋め（ディレーション）を設定し、**① 法線マップをベイク（まとめて1枚）** を押します。
   - 複数メッシュは**同じUV空間の1枚**へまとめて焼き込まれ、単一の法線/陰影になります。
5. `ライト方位/仰角` などを調整すると、**② 陰影マスク**がリアルタイムに更新されます（自動更新ON時）。
6. **法線マップを保存 / 陰影テクスチャを保存** で PNG 出力します。

> 複数メッシュを1枚にまとめる前提として、対象メッシュ群が**同じテクスチャ(UVレイアウト)を共有**している必要があります。
> それぞれ別のUV空間を持つ場合は、UVアイランドが重なって正しく焼けません。

## 各設定

| 項目 | 説明 |
|------|------|
| 解像度 | 出力テクスチャの一辺サイズ (256〜4096) |
| 法線空間 | `Object`=配置に依存しない安定した結果 / `World`=シーン上の向きを反映 |
| 縁の埋め(px) | UVアイランド外周を埋めてシーム（縫い目）のにじみを軽減 |
| Y反転 | 出力が上下反転する場合にON |
| ライト方位(Yaw) / 仰角(Pitch) | 陰影を付けるライトの向き |
| コントラスト | 陰影の強さ（0.5 中心を保ったまま増減） |
| アンビエント | 影側の下限を持ち上げる（真っ黒を防ぐ） |
| 出力モード | `Mask`=グレースケール陰影 / `AlbedoTimesShade`=アルベド×陰影 |

## 陰影方式（Lambert / Cavity）

`方式` で2種類から選べます。

- **LambertLight**: 法線とライト方向の内積による陰影。`ライト方位/仰角`で向きを調整。
- **Cavity（凹凸 / 影の出やすさ）**: ライト方向を使わず、**周囲の壁がこちらを向いている度合い（オクルージョン）**で
  白黒が決まります。各ピクセルの周囲を `探索半径(px)`（既定5px）の複数方向×複数半径で探索し、
  **影が出やすい(谷/凹＝壁に囲まれた窪み)=黒 / 出づらい(凸/開けている)=白 / 平坦=グレー**。
  窪みは縁だけでなく**領域全体が暗く**なります（AO/キャビティ寄り）。
  基準グレー(0.5)は**テクスチャ全体の平均**に対応します。
  `探索半径`（広い窪みを面で暗くしたいほど大きく）・`探索方向数`・`強さ`・`自動正規化`・`白黒反転` で調整。
  ※ CPU計算のため、パラメータ変更後は **② 陰影を更新** ボタンで再計算します（自動更新はLambertのみ）。

## 陰影マスクの値について

法線 N とライト方向 L に対し、`shade = dot(N, L) * 0.5 + 0.5` で出力します。

- ライトに正対する面 … **1.0（白）**
- ライトに直交する面 … **0.5（中間）**
- ライトに背を向ける面 … **0.0（黒）**

「中間が 0.5」になるため、シェーダで **乗算レイヤー**や **Half-Lambert 的なランプ**として扱いやすい値です。
`Mask` で保存した PNG は、インポート時に **sRGB を OFF（Linear）** にすると計算どおりの値で使えます。

## 実装メモ

- 法線ベイクは、頂点シェーダで **UV を直接クリップ座標に変換**して UV 空間へ描き込みます（`NormalBake.shader`）。
  そのため MVP 行列に依存せず、`Graphics.DrawMeshNow` で確実にベイクできます。
- 法線は **オブジェクト空間**でエンコード（rainbow 系）。陰影計算はこの空間の法線とライト方向で行います。
  一般的な青いタンジェント空間法線マップが必要な場合は別途変換が必要です（本ツールは陰影生成が目的）。
- `Dilation.shader` で UV アイランド外周を数 px 埋め、ミップやフィルタ時のシームを軽減します。
