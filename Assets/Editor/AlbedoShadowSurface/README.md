# Albedo Shadow Surface (Unity Editor 拡張)

アルベドテクスチャから**影面（シャドウ）テクスチャ**を生成する Unity エディタ拡張です。

- **基本**: アルベド × 任意の値(0〜1) の乗算。
- **オプション（OKLCH補正）**: 単純な RGB 乗算だと暗部の色がくすみがちなところを、
  **OKLCH 空間で L（知覚明度）だけを減衰**させ、彩度 C・色相 H を保持することで、
  色味を保ったまま自然に暗くします。補正量スライダで RGB 乗算との間をブレンドできます。

## 導入

1. `AlbedoShadowSurface` フォルダを、プロジェクトの `Assets` 以下にコピーします。
   - `Assets/AlbedoShadowSurface/Editor/*.cs`
2. コンパイル後、メニューに **Tools > Albedo Shadow Surface** が追加されます。

> 動作確認想定: Unity 2020.3 LTS 以降。Read/Write を有効にしていないテクスチャでも動作します
> （内部で Blit 経由で読み取ります）。

## 使い方

1. **Tools > Albedo Shadow Surface** を開く。
2. `アルベドテクスチャ` を割り当てる。
3. `乗算値` を調整（1=元のまま、0=真っ黒）。これだけで基本の乗算影面になります。
4. 必要なら `OKLCH補正を使う` をON。`補正量` を上げるほど OKLCH-L 減衰が強く反映されます。
5. `影面テクスチャをPNG保存` で出力。

## パラメータ

| 項目 | 説明 |
|------|------|
| 乗算値 | `albedo × 値`。基本の暗さ。0〜1。 |
| OKLCH補正を使う | ONで知覚的な暗さ補正を有効化 |
| 補正量 | 0=単純RGB乗算 / 1=OKLCH空間でのL減衰。中間はブレンド。 |
| 影部の彩度 | OKLCHのa,bを倍率変更。1=保持、<1でくすみ、>1で鮮やか。 |
| 影のティント | 影に色を乗せる（白=無効）。 |
| Lグレースケールを生成 | OKLCHの L を可視化・書き出し。`min-max正規化` で 0..1 に伸長。 |

## Alpha出力（白黒テクスチャ）

`Alpha用テクスチャ` に白黒（グレースケール）テクスチャを割り当てると、その値を出力の
**Alphaチャンネルにそのまま書き込み**ます。RGB（影面）はこれまで通りで、Alphaにだけ白黒情報が入ります。

- `読取チャンネル`: 割り当てたテクスチャの R/G/B/A/輝度 のどれをAlphaに使うか
- `反転`: 値を 1-x で反転
- 未指定の場合、Alphaは元アルベドのAlphaのままです。
- 入力サイズが異なっても、出力（アルベド）解像度にバイリニアで合わせます。
- 出力PNGは RGBA なので、Alphaはそのまま保存されます。

## OKLCH補正の考え方

RGB を一律に `×0.5` すると、明るい面と暗い面で「見た目の暗くなり方」が不均一になり、
彩度の高い色は濁って見えがちです。本ツールの OKLCH 補正は、

1. sRGB → linear → OKLab → OKLCH に変換
2. **L（明度）だけを乗算値で減衰**（`L' = L × 乗算値`）、`a,b` は保持（＝彩度 C・色相 H を保持）
3. OKLCH → linear → sRGB に戻す

という手順で、**色相・彩度を保ったまま知覚的に自然な暗さ**を作ります。
`補正量` はこの OKLCH 結果と単純 RGB 乗算結果の線形補間割合です。

## 実装メモ

- 色変換はすべて C#（CPU）で明示的に実装しており、プロジェクトが Linear / Gamma いずれの
  カラースペースでも同じ結果になります（`ShadowSurfaceCore.cs`）。
- OKLab 変換係数は Björn Ottosson の定義に準拠。
- プレビューは軽量化のため最長辺 512px に縮小して表示し、保存時は元解像度で処理します
  （ピクセル独立処理のため縮小プレビューと最終結果の値は一致します）。
