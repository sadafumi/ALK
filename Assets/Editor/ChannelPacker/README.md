# Channel Packer (Unity Editor 拡張)

R / G / B / A のそれぞれに**別々のグレースケール（テクスチャ）を割り当て**、
1 枚のテクスチャに合成して出力する Unity エディタ拡張です。
マスクマップ（例: R=Metallic, G=AO, B=Height, A=Smoothness）や、各種データマップの作成に使えます。

## 導入

1. `ChannelPacker` フォルダを、プロジェクトの `Assets` 以下にコピーします。
   - `Assets/ChannelPacker/Editor/*.cs`
2. コンパイル後、メニューに **Tools > Channel Packer** が追加されます。

> 動作確認想定: Unity 2020.3 LTS 以降。入力テクスチャは Read/Write を有効にしていなくても動作します
> （内部で Blit 経由で読み取ります）。

## 使い方

1. **Tools > Channel Packer** を開く。
2. R / G / B / A の各スロットにテクスチャを割り当てる。
3. スロットごとに以下を設定:
   - `読取チャンネル`: そのテクスチャの R/G/B/A/輝度 のどれをこの出力チャンネルへ入れるか
   - `反転`: 値を 1-x で反転
   - `定数値`: テクスチャ未指定のスロットに入れる固定値（例: Aを常に1.0）
4. `カラースペース` と `解像度モード` を設定。
5. `パックしてPNG保存` で出力。Assets 配下に保存すると、インポート設定の sRGB も自動で合わせます。

## パラメータ

| 項目 | 説明 |
|------|------|
| 読取チャンネル | 入力テクスチャの R/G/B/A、または 輝度(Rec.709) を選択 |
| 反転 | そのチャンネルを `1 - value` に反転 |
| 定数値 | テクスチャ未指定スロットの固定値 (0..1) |
| カラースペース | `Linear`=マスク/データマップ向け(sRGB OFF) / `sRGB`=見た目重視 |
| 解像度モード | `Auto`=割り当てた入力の最大サイズ / `Manual`=幅・高さを手動指定 |

## 仕様メモ

- 各スロットは独立にサンプリングされ、サイズの異なる入力もバイリニアで出力解像度に合わせます。
- 値は 0..1 のストア値として素直にパックします（ガンマ変換は行いません）。
  データマップ用途では `Linear` を選び、インポート時 sRGB OFF で使うのが基本です。
  `Linear` 保存時は自動で sRGB フラグを OFF、`sRGB` 保存時は ON に設定します（Assets 配下の場合）。
- 輝度は Rec.709 係数 `0.2126 / 0.7152 / 0.0722` を使用。
- A スロットは既定で定数 1.0（不透明）になっています。
