# Leather Normal Generator (Unity Editor 拡張)

ライダースジャケットなどの**レザー質感のノーマルマップ**を手続き生成する Unity エディタ拡張です。
革のシボ（粒状の凹凸）・折りジワ・うねり・銀面のざらつきをハイトマップとして合成し、ノーマルマップへ変換して PNG 出力します。
すべてラップ格子で計算しているため、出力は**シームレスにタイリング**できます。

- **シボ**: Worley（セルラー）ノイズ。セル内の盛り上がり＋セル境界の溝。細かいシボの二重重ねに対応
- **シワ**: リッジ状 fBm ノイズ。異方性パラメータで横方向に走る着用ジワを表現
- **うねり**: 低周波 fBm による革表面の緩やかな起伏
- **微細**: 高周波ノイズによる銀面のざらつき

## 導入

1. `LeatherNormalGenerator` フォルダをプロジェクトの `Assets` 以下にコピーします。
2. コンパイル後、メニューに **Tools > Leather Normal Generator** が追加されます。

## 使い方

1. **Tools > Leather Normal Generator** を開く。
2. プリセット（`シボ強め` / `スムース` / `ヴィンテージ`）を選ぶか、各パラメータを調整。
3. プレビュー表示を `ノーマル` / `ハイト` / `ライティング` で切り替えて質感を確認
   （`ライティング` はライト角度を回して凹凸の見え方をチェックできます）。
4. `出力解像度` を選んで `ノーマルマップを保存`。
5. Assets 配下に保存すると、Texture Type = **Normal map**・Wrap = Repeat を自動設定します。

## パラメータ

| 項目 | 説明 |
|------|------|
| シード | 同じ値なら同じ模様を再現。`乱数` ボタンでランダム化 |
| シボ: 細かさ | タイル1辺あたりのセル数。大きいほど粒が細かい（シュリンク→スムース） |
| シボ: 盛り上がり / 溝の深さ / 溝の幅 | セル内の膨らみとセル境界の溝の形状 |
| シボ: 高さばらつき | セルごとのランダムな高低差。革らしい不均一さが出る |
| シボ: 細かいシボを重ねる | 3倍の細かさのシボを弱く重ねて粒感を追加 |
| シワ: 深さ / 細かさ / 鋭さ | 折り目の谷の深さ・周期・エッジの鋭さ |
| シワ: 異方性 | 1=等方 / 大きいほど横方向に走るシワ（袖・胴の着用ジワ向け） |
| うねり量 / 周期 | 革表面の緩やかな起伏 |
| ざらつき量 / 周期 | 銀面の微細凹凸 |
| 凹凸の強さ | ハイト→ノーマル変換時の勾配スケール（512px基準で解像度補正） |
| Green(Y)反転 | DirectX系規約の場合ON（Unity標準はOFF） |

## メモ

- プレビューは 512px で計算し、保存は指定解像度で再計算します。強さは解像度補正しているため見た目は一致します。
- 「ハイトマップも一緒に保存」をONにすると `_Height.png` を並べて出力します（視差マップやマスク作成の素材用）。
- 出力はシームレスタイル対応。マテリアル側で Tiling を上げてスケール調整できます。
- パラメータは EditorPrefs に保持され、ウィンドウを閉じても復元されます。

## フォルダ構成

```
LeatherNormalGenerator/
└── Editor/
    ├── LeatherNormalCore.cs    # ノイズ生成・ハイト合成・ノーマル変換・保存
    └── LeatherNormalWindow.cs  # EditorWindow (Tools > Leather Normal Generator)
```
