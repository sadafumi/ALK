# SDF Texture Generator (Unity Editor 拡張)

複数枚の白黒グラデーション（顔影などの各段階マスク）を、**1枚の段階的SDFテクスチャ**へ合成する
Unity エディタ拡張です。セルルックの顔影をライト方向で動かす用途を想定しています。

参考記事: <https://note.com/rid_316/n/ne967527e86ff>

8bitだと寄ったときに段差・ジャギーが出るため、**RG2チャンネルで16bit相当（65,536段階）**にパックして
滑らかにできます。真の高精度が必要な場合は EXR(Float) 出力も選べます。

## 導入

1. `SdfTextureGenerator` フォルダをプロジェクトの `Assets` 以下にコピーします。
2. コンパイル後、メニューに **Tools > SDF Texture Generator** が追加されます。

> Unity 2020.3 LTS 以降想定。入力は Read/Write 無効でも動作します（内部でBlit読み取り）。

## 使い方

1. **Tools > SDF Texture Generator** を開く。
2. `段階テクスチャ` に、ライトが動く各段階の白黒マスク／グラデーションを **明→暗の順** に並べて追加。
   （`▲▼` で並べ替え、`選択中を追加` でまとめて追加できます）
3. `合成モード` を選ぶ。
4. `精度/形式` と `解像度モード` を設定。
5. `SDFテクスチャを保存`。Assets 配下に保存するとインポート設定の sRGB を自動で OFF にします。

## 入力方式

`入力方式` で2通りから選べます。

- **Stages（手動）**: 各段階の白黒マスク／グラデーションを明→暗の順にリストで指定します（従来どおり）。
- **NormalSweep（自動）**: **ノーマルテクスチャと段階数だけ**指定すれば生成します。
  指定したノーマルに対してライトを `スイープ開始角` → `スイープ終了角` へ `段階数` ぶん回し、
  各段階の陰影（N·L）を内部生成して、そのまま合成・SDF化します。

  | 項目 | 説明 |
  |------|------|
  | ノーマルテクスチャ | スイープ対象のノーマルマップ |
  | 段階数 | ライトスイープの分割数（＝内部生成する段階マスクの枚数） |
  | スイープ開始角 / 終了角 | ライトを回す水平角の範囲（既定 -90°〜+90°） |
  | 仰角 | ライトの上下角 |
  | Green(Y)反転 | 法線マップのGが逆の場合ON |

  → 顔影用なら、顔のノーマルを入れて段階数を決めるだけでSDFの下地が作れます。仕上がりは合成モード
  （Average / DistanceBlend など）や角度範囲で調整してください。

### AnimeXD方式（各角度の生成→合成を1ツールで完結）

参考: <https://note.com/ca__mocha/n/n9289fbbc4c8b>

顔の正面からの光の角度 **0°, 22.5°, 45°, 67.5°, 90°, 112.5°, 135°, 157.5°, 180°（計9枚）** で
各角度の「光の当たり具合」を生成し、1枚のSDFへ合成します。枚数は減らしても構いません（影が少しシンプルになるだけ）。

- `プリセット: AnimeXD 9角度 (0°→180°)` を押すと、開始角0°／終了角180°／段階数9／合成モード ThresholdStack に一括設定します。
- ノーマルにライトを各角度で当てた**中間テクスチャ**は、プレビュー下部にサムネイル表示されます。
- `各角度の中間テクスチャを書き出す (a,b,c…)` で、各角度の白黒テクスチャを `a_000deg.png` … の名前でフォルダへ書き出せます
  （外部ツールへ渡したい場合や確認用）。
- そのまま `SDFテクスチャを保存` すれば、生成→合成→出力まで1ツールで完了します。

合成モードは、はっきりした段階が欲しい場合 `ThresholdStack`、段差を滑らかにしたい場合 `DistanceBlend` が目安です。
精度は 16bit相当の `PackedRG16` を使うと段差・ジャギーが目立ちにくくなります。

## 合成モード

| モード | 説明 |
|--------|------|
| Average | 各段階（グラデーション）の平均。入力が既に滑らかなグラデならこれが基本 |
| ThresholdStack | 各段階を `しきい値` で2値化し、条件を満たす段階数 / N。2値マスク列から段階SDFを作る |
| DistanceBlend | 各段階を `しきい値` で2値化→符号付き距離変換し、`距離レンジ(px)` で正規化してブレンド。少ない枚数でも滑らか |

## 出力精度

| 形式 | 説明 |
|------|------|
| Gray8 | 8bit グレースケール PNG。手軽だが段差が出やすい |
| PackedRG16 | 16bit相当を R(上位)+G(下位) にパックした PNG。Unity の `DecodeFloatRG` 互換 |
| ExrFloat | EXR（Float）。真の高精度。エンジン側がEXR/Floatを読める場合に |

## シェーダでの復号・使用例

PackedRG16 で出力したテクスチャは、`sRGB` を OFF（Linear）でインポートし、次のように復号します。

```hlsl
// UnityCG.cginc の DecodeFloatRG と同等
float DecodeFloatRG(float2 enc)
{
    return dot(enc, float2(1.0, 1.0 / 255.0));
}

// 顔影SDFの使用イメージ
fixed4 frag (v2f i) : SV_Target
{
    float sdf = DecodeFloatRG(tex2D(_FaceSDF, i.uv).rg); // 0..1
    // lightParam: ライトの水平角などから 0..1 を作る（例: N·L を 0..1 に）
    float lightParam = saturate(_LightParam);
    // sdf < lightParam の側を「明」にする（向きは必要に応じて反転）
    float lit = step(sdf, lightParam);
    // 境界を柔らかくするなら smoothstep
    // float lit = smoothstep(sdf - _Feather, sdf + _Feather, lightParam);
    ...
}
```

Gray8 の場合は `tex2D(_FaceSDF, uv).r` をそのまま使います。

## 仕様メモ

- 距離変換はチャンファー近似（重み 1 / √2 の2パス）による符号付き距離です。厳密なユークリッドではありませんが、
  スムージング用途には十分です。
- 各段階はサイズが異なっても出力解像度にバイリニアで揃えます。
- `PackedRG16` は `[0,1)` を Unity の `EncodeFloatRG` と同じ式でパックしています（1.0 は僅かに内側へクランプ）。
- プレビューは軽量化のため縮小・8bit表示です（距離レンジは解像度比でスケールして見た目を合わせています）。保存は出力サイズ・指定精度で処理します。
